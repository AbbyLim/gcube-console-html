새 노드 연결

GPU 공유를 시행할 장치에서 gcube agent를 실행하여 인증해주세요.
원활한 GPU 공유를 위하여 일부 장치에서는 설치가 불가할 수 있습니다.

[설치 기본 사양]

  • CPU 12 스레드(thread) 이상
  • Memory 16GB 이상
  • 512GB SSD 이상
  • Nvidia RTX 2060
  • (GPU memory 7GB 이상)
  • ※ Windows 10 Pro 22H2 이후
  • ※ Nvidia Driver Version 550
